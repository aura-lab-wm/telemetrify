AI-Pulse Menubar Redesigns

Five distinct directions for the RoccoPulse menubar popover — each a fully rendered, pixel-faithful mockup at the real ~480px width. The current build packs a lot of signal (GPU pressure, tier fallback, service control) into one tight surface; these explorations push that signal in five different aesthetic and ergonomic directions, from native macOS vibrancy to a dense ops console. Every mockup carries the same live data so trade-offs are honest.

01

Native Glass

macOS vibrancy & depth

Leans fully into the platform: translucent vibrancy material, soft inner glows, and rounded "cards" that feel poured from the same glass as Control Center. It tames the current edge-to-edge density by grouping services into framed rows and softening the GPU bars, so the popover reads as part of macOS rather than a bolted-on dashboard.

Implementation notes

  • Use NSVisualEffectView / SwiftUI .background(.ultraThinMaterial) on the popover root for true vibrancy.
  • Service rows are RoundedRectangle cards with .fill(.white.opacity(0.04)) + hairline .stroke.
  • SF Symbols: server.rack, cpu, magnifyingglass, arrow.clockwise. Status LEDs are Circle() with .shadow(radius:) glow.
  • GPU bars: stack two Capsule()s in a ZStack; the cyan mem bar uses .blendMode(.screen) to layer over magenta.
  • Picker maps cleanly to a SwiftUI Menu styled with .menuStyle(.borderlessButton).
02

Mission Control

dense ops terminal

For the operator who lives in tmux. Monospace everything, a tabular GPU grid with aligned columns, and phosphor-green accents make hotspots scannable in a glance. It trades warmth for information density — the same popover surfaces more rows without scrolling and reads like a live watch nvidia-smi.

Implementation notes

  • Set the whole tree in .font(.system(.body,design:.monospaced)); columns align via fixed-width HStack frames.
  • GPU grid is a Grid (macOS 13+) or LazyVGrid with GridItem(.fixed) for tabular columns.
  • Temperature turns amber/red with a simple .foregroundStyle(temp > 68 ? .orange : .secondary) threshold.
  • Phosphor glow = .shadow(color:.green.opacity(0.6),radius:4) on bars and LEDs.
  • Highest information-per-pixel of the five; ideal as an optional "compact / pro" view toggle.
03

Swiss Light

minimal & legible

A calm, light-mode counterpoint built on whitespace, a strict type scale, and a near-monochrome palette where blue is reserved for the memory metric alone. Underline tabs and divider-only rows remove visual noise, making it the most screenshot-friendly and the easiest to read at a glance in bright environments.

Implementation notes

  • Honor system appearance: drive colors from Color(.windowBackgroundColor) / semantic colors so dark mode flips for free.
  • Tabs use a .background(alignment:.bottom) underline indicator with matchedGeometryEffect for the slide.
  • Rows are plain Divider()-separated HStacks — no card chrome, minimal layer count.
  • Type scale maps to .title3 / .body / .footnote / .caption; metrics use .monospacedDigit().
  • Cheapest to render — fewest gradients/shadows, best for low-power and Reduce Transparency users.
04

Data-Viz Forward

ring gauges & sparklines

Reframes GPUs as glanceable instruments: a 2×2 grid of radial utilization gauges, memory sparklines, and a KPI strip summarizing fleet pressure up top. Instead of four near-identical bars, the operator sees shape and trend instantly — and the summary KPIs answer "is anything free?" before the eye reaches row level.

Implementation notes

  • Ring gauges = native SwiftUI Gauge(value:){}.gaugeStyle(.accessoryCircularCapacity), or a trimmed Circle().trim(from:to:) for full color control.
  • Sparklines: tiny Chart { BarMark } (Swift Charts) fed from a rolling buffer of recent polls.
  • KPI strip is derived state — compute avg util / free count / peak temp from the GPU array.
  • 2×2 LazyVGrid with two flexible columns keeps it within 480px; gauges are .fixedSize().
  • Best storytelling for "why are we on Tier 0" — the gauges make saturation visceral.
05

Neon Cyberpunk

magenta/cyan, dialed up

Takes the existing magenta-and-cyan GPU bars and commits — glowing edges, uppercase display type, and a gradient Start button that demands a tap. It's the most shareable and "rig"-flavored of the set, ideal for an enthusiast GPU box, while still keeping the amber tier warning legible against the dark plum backdrop.

Implementation notes

  • Glow = layered .shadow + .blur behind Capsule() bars; cyan mem bar keeps .blendMode(.screen).
  • Display type via a Space Grotesk bundled font; metrics stay monospaced for stability.
  • Start button is a LinearGradient(.cyan → .pink) with an animated .shadow pulse on appear.
  • Respect Reduce Motion / Reduce Transparency: gate glows and pulses, fall back to Design 03's flat palette.
  • Highest "TikTok moment" potential; risk is legibility — keep text contrast ≥ 4.5:1 on the plum bg.
