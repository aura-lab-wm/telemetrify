The sections

Turns

Your raw timeline. Filter by model, project (cwd), date, errors, follow-ups, latency, tokens. Click any card to open the full transcript.
Clusters

Prompts grouped by semantic similarity. Surfaces patterns: "I'm always asking Claude to do this." Big clusters → candidates for a Skill or a doc.
Queue

Smart rerun candidates: which past prompts would benefit most from being replayed against the current claude CLI? Replay and diff the new result against the original.
Ask

Natural-language Q&A over the corpus. "When did I last debug a sqlite-vec issue?" Answers stream in with inline citations.
Dashboard

10 charts of historical telemetry: turns/day, tokens by model, tool-call heatmap, error rate, p50/p95 latency, cache efficiency, correction rate, top clusters.
Health JSON

Capture lag, schema version, vector / FTS / cluster coverage, recent capture errors. Use it as a Doctor signal or to wire alerts.

Search & filter syntax

Every filter is a URL query param on /. Combine them freely. Bookmark or paste a URL with the chips already applied — that's the entire DSL.

ParamWhat it doesExample
qHybrid semantic + BM25 search/?q=sqlite migration
since / untilDate range (ISO YYYY-MM-DD)/?since={{ today }}
modelExact model match/?model=claude-opus-4-7
cwd_globLIKE pattern on cwd (* wildcards)/?cwd_glob=*/telemetrify*
has_error=1Only turns whose tool calls errored/?has_error=1
has_followup=1Only turns that triggered a follow-up / retry/?has_followup=1
has_annotation=1Only turns you've manually annotated/?has_annotation=1
min_latency_msOnly slow turns/?min_latency_ms=10000
min_tokensOnly big turns/?min_tokens=50000
origin=rerunOnly replayed turns/?origin=rerun
